# Nordic Living – WordPress-tema

## Om projektet
Nordic Living är en webbplats för ett fiktivt företag inom skandinavisk inredning och möbler. Projektet är utvecklat inom Laboration 4.2 och bygger vidare på den statiska webbplatsen från moment 4.1.

Webbplatsen är byggd med WordPress och använder ett egenutvecklat, fristående WordPress-tema.

## Publicerad webbplats
https://nordicliving.infinityfree.me

## Funktioner
- Egen startsida med presentation av företaget.
- Nyhetssida med inlägg, utvalda bilder och utdrag.
- Separata sidor för Om oss, Kontakt och AI-redovisning.
- Egna sidmallar för olika sidtyper.
- Kontaktformulär med WPForms.
- Widgetområde i sidfoten.
- SEO-inställningar med Yoast SEO.
- Besöksstatistik med Google Analytics via Site Kit.
- Användarroller för administratör och redaktör.

## Tekniker
- WordPress
- PHP
- HTML
- CSS
- Git och GitHub

## Installerade tillägg
- WPForms Lite – kontaktformulär.
- Yoast SEO – sökmotoroptimering.
- Site Kit by Google – besöksstatistik.
- W3 Total Cache – cache och prestanda.

## Tema
Temat heter Nordic Living och är egenutvecklat. Det är ett fristående tema och inte ett child theme.

## AI-verktyg
ChatGPT har använts som stöd under utvecklingen av PHP, HTML, CSS, WordPress-inställningar och webbplatsens texter. En mer utförlig redovisning finns på webbplatsens undersida AI-redovisning.
